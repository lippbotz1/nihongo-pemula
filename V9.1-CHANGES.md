- Lifetime tetap tidak memiliki expiry.
- Halaman user memeriksa lisensi otomatis setiap 15 detik dan mengunci kembali aplikasi jika lisensi expired/dinonaktifkan.
- Admin dashboard ditambah pencarian user, statistik, dan tombol ganti password.
- Admin tidak bisa menonaktifkan atau menghapus akun admin yang sedang dipakai.
- Durasi API dibatasi hanya 30/90/365/Lifetime.
- Paket ZIP dibersihkan: satu root project siap deploy, tanpa folder duplikat v9work.
